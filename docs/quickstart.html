快速上手 ​

本章带您在十分钟内跑通一个完整流程：创建项目 → 配置模型 → 空间扫描 → 军团渗透 → 漏洞分诊与导出。

前置条件

  • 已按 下载与安装 解包并成功启动
  • 测试目标为您已获得书面授权的系统（本地靶场亦可，如 DVWA）

第一步：创建项目 ​

  1. 启动主程序，进入首页（项目列表）
  2. 点新建项目，填写项目名称（如 某授权项目 - 一期）
  3. 进入项目即可开工 —— 目标在下发扫描或交给军团时直接填写，平台会自动把它登记到项目里

所有模块的数据都归属于当前项目，互不串扰。项目内左侧是 7 个执行面板：仪表盘 / 军团 / 漏洞管理 / 漏洞测绘 / 云上综合 / 空间扫描 / 空间测绘。

第二步：配置大模型 ​

军团需要一个大模型 Provider 才能工作：

  1. 打开系统配置 → 大模型配置
  2. 新建或启用一个 Provider，填写接口格式（OpenAI 兼容 / Anthropic Claude 等）、Base URL 与 API Key
  3. 保存后可先做一次连通性验证

建议

推荐选择支持**函数调用（Tool Use）**的模型，军团的工具调度体验最佳。若遇到「大模型连接失败」，先调大模型请求超时与流式空闲超时。

第三步：空间扫描 ​

  1. 打开项目的空间扫描页
  2. 填写目标（支持 IP / CIDR / 域名），选一个端口模板
  3. 点击开始扫描，实时查看端口、服务、Web 标题、TLS 证书与 IP 归属
  4. 扫描结束后，开放 Web 服务的端口可联动漏洞测绘做站点分析

第四步：军团渗透 ​

  1. 打开项目的军团页，在会话列表新建会话，选择合适的角色（红队 / 渗透 / CTF / 侦察）

  2. 用一句话下达任务，例如：

    对 10.1.5.1 进行授权渗透测试，目标是发现并验证全部可利用的漏洞，输出报告。

  3. 观察军团自动推进：拆解任务、并行验证、回收结论，直到任务完成

  4. 每次探测、截图、证据提交都会留痕；右侧面板可查看并行任务、浏览器画面与工具调用记录

军团可能自动做了什么？
  • 端口扫描与服务识别
  • 对发现的 Web 站点做指纹与目录探测
  • 通过测绘结果定位可疑入口
  • 用浏览器登录、截图、抓取动态内容
  • 调用 Kali / WSL 工具箱执行内网命令（如已配置）
  • 把验证过的发现写入漏洞账本

想更稳妥地开跑

  • 先看计划：点输入框的计划按钮，军团只做被动侦察并给出一份计划，确认后点「批准并执行」
  • 收紧权限：点权限按钮切到「只读」或「工作区写入」，命令执行与写操作会被拦截
  • 强制隔离：在系统配置 → 智能体 → 执行环境中选「必须隔离」，没有容器时命令直接拒绝执行

第五步：漏洞分诊与导出 ​

进入项目的漏洞管理页：

  • 发现 页签按严重度分诊：顶部风险带看整体态势，下面是档位泳道，每条发现可展开证据、跳回产生它的会话
  • 侦察报告 页签按资产归集，可单个或批量导出 Markdown / PDF
