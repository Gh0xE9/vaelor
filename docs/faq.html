常见问题 ​

找不到扫描 / 项目数据 ​

数据保存在数据目录（Windows 默认为程序所在目录，macOS 为系统的应用数据目录）。若把数据目录放到过其他位置，请到那里查找。

启动提示「数据目录已被另一个进程占用」 ​

同一份数据目录不能同时被两个实例打开。关掉已在运行的窗口后重试；确实需要同时开多份，请让每个实例各自使用一份独立的数据目录。

数据库被锁定 ​

确保没有其他 VAELOR 实例在运行。如果确实没有，重启程序即可解决。

军团不调用工具 ​

  • 确认所选模型支持函数调用（Tool Use）
  • 确认角色的工具开关已启用
  • 在系统配置里验证 Provider 连通性
  • 若开了计划模式，主动扫描与利用类工具会被拒绝，这是预期行为

军团总在危险动作前弹确认 ​

这是高危操作人工确认：破坏性命令、反弹 Shell、横向移动、远程批量执行会弹确认卡；普通 PoC 命令（curl / wget 探测）不会打扰。确认卡可勾选「批准并在本会话内自动批准」，超时未响应视为拒绝。

权限被降档了 / 完全访问没被记住 ​

完全访问档不持久化：重开程序会回落为「工作区写入」，界面顶部有提示，点**「恢复完全访问」**即可改回（需二次确认）。

命令报「必须隔离执行，但没有可用隔离环境」 ​

执行隔离档位选了**「必须隔离」**，但 Docker 与 WSL 工具箱都没启用。二选一：启用工具箱，或把档位改为「优先隔离」/「不隔离」。

报告里的证据写着来自历史运行 ​

这是有意的区分：只有属于本次运行的会话才计入本次战果。看到「本次运行未取得证据（证据来自历史运行）」，说明该条证据取自同项目更早的运行，需重新取证。

漏洞管理里没有「漏洞报告」页签 ​

发现页签就是权威的漏洞账本：跨任务汇总、严重度分诊、证据内联；导出能力在侦察报告页签（按资产归集，Markdown / PDF）。

想切换界面语言 ​

系统配置 → 外观与语言，可选简体中文 / English / 한국어。未手动选择时会自动跟随系统语言。

IP 归属全部显示「未知」 ​

缺少 IP 归属离线库。补上数据文件或用环境变量指定路径；缺库不影响其他字段。

MCP 工具从军团工具表里消失了 ​

MCP Server 未启用或连不上时，该 Server 的整批工具会一并消失（不是逐个报错）。检查 Server 开关、本地进程是否存活，或远端地址是否可达。

企业微信只收到部分消息 / 收不到 ​

企业微信单条消息有长度上限，超出会被整条拒收，所以平台会把汇总拆成多条发送。收不到则检查「开关是否打开」与「推送阈值是否高于该漏洞级别」。

配了代理但流量没走代理 ​

启用条件是「开关打开 且 链上至少有一个节点」，两个条件缺一不可。详见代理与网络出口。

想要内网渗透能力 ​

内网攻击依赖工具箱：优先推荐 Kali Docker 工具箱；无法安装 Docker 的 Windows 环境可使用 WSL 工具箱。

更多排障 ​

各项限制与静默降级清单见排障手册。
