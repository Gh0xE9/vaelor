空间测绘 ​

空间测绘对接主流测绘平台，把外部资产数据一键拉入项目，与本地扫描结果交叉关联。

支持的平台 ​

平台说明
FOFA网络空间测绘搜索引擎
Quake360 网络空间测绘
Hunter鹰图平台
Shodan全球联网设备搜索引擎

API 凭据在系统配置 → 空间测绘中统一管理，支持配置多个平台，并查看各自的积分余额、会员等级等账户信息。

查询模式 ​

模式行为
原生语法直接使用平台自己的查询语法
域名模式输入域名，自动剥离协议与路径后查询
IP 模式走 IP 专属语法
自动判别自动判断输入是域名还是 IP 并选择语法

域名 / IP 模式下查询内容不能为空。

结果处理 ​

  • 分页拉取 —— 大结果集分批取回
  • 去重入库 —— 与项目已有资产自动合并去重
  • 交叉关联 —— 与空间扫描结果相互印证

常用参数 ​

参数说明
平台一次任务选择一个平台
最大页数分页拉取上限
每页条数受各家 API 约束
全量模式仅 FOFA：查询全量数据而非仅近一年
超时单平台请求超时

FOFA 字段权限会自动降档

FOFA 按会员等级开放不同字段，低等级账号请求高等级字段会报「没有权限搜索 X 字段」，平台会自动降档重试，不必手工改语法。

典型流程 ​

  1. 在系统配置 → 空间测绘中填入平台 API Key
  2. 在项目空间测绘页选择平台与查询模式
  3. 输入目标或语法，执行查询
  4. 预览结果后选择入库，进入项目资产
