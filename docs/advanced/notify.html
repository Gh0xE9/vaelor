消息通知 ​

消息通知把作业进展与漏洞告警推送到飞书 / 企业微信群机器人，适合团队协作与值班值守。

推送什么 ​

类型内容
漏洞告警新发现的漏洞条目，按严重级别着色
任务汇总军团会话结束后的总结，按站点分组

配置 ​

系统配置 → 消息通知：

  1. 新建通知组，组内添加一个或多个 Webhook
  2. 每个 Webhook 选择平台（飞书 / 企业微信），填完整地址或只填 token / key
  3. 设置推送阈值：达到指定严重级别才推送
  4. 在项目里可指定使用哪些通知组；未指定时推送到全部已启用组

注意事项 ​

  • 开关必须打开：只在设置里填了 Webhook 但没启用，不会推送
  • 企业微信单条消息有长度上限，超出会被整条拒收，因此汇总会拆成多条发送，属正常行为
  • 飞书汇总卡片有展开上限，超出部分会显式标注「以及其他 N 个」，完整清单请到漏洞管理查看
  • 收不到消息时，依次检查：开关、推送阈值、机器人是否被群管理风控

测试 ​

通知组里的每个 Webhook 都可以单独发送测试消息，先确认链路通再接真实推送。
