漏洞测绘 ​

漏洞测绘对站点做深度分析：全站爬虫、指纹识别、敏感信息提取、目录探测、资产侦察，并可把值得深挖的站点直接交给军团。

全站爬虫 ​

  • SPA 渲染 —— 用浏览器加载动态内容，单页应用不再是盲区
  • API 端点发现 —— 从流量与前端代码中还原接口清单
  • 协议自动探测 —— 只给 IP 或端口时，自动判断 http / https 再开爬
  • 手动 URL 爬取与批量导入 —— 补充指定页面或整份 URL 清单
  • 资源树浏览 —— 按页面 / JS 分类查看站点资源
  • 断点续扫 —— 大批量任务中断后可继续

指纹识别 ​

  • 内置指纹规则库，随包提供，无需额外配置
  • 命中结果按重要程度分层排序：产品 → 技术栈 → 通用特征，站点图标命中优先
  • 可按重要指纹或站点图标分组筛选（同图标站点往往同一套系统）

敏感信息提取 ​

自动从页面与 JS 中识别并标记：

  • Token、API Key、密码、JWT
  • 云厂商 AK / SK 等凭据
  • 内部 IP、内部域名、内网地址
  • 身份证、手机号、邮箱等个人信息
  • SSRF 可疑参数、API 路径与前端路由

结果汇总在敏感信息抽屉里，可按站点跳回详情。

目录探测 ​

在测绘任务里对选中站点批量发起（工具条「更多 → 目录扫描」）：

  • 内置多套字典（短 / 中 / 长 / 后缀 / 敏感 API）
  • 支持 GET / POST 两种方法
  • 可选递归下钻
  • 并发度可调，按目标承载能力设置
  • 结果异步排队，完成后在站点详情里查看

资产侦察 ​

对已完成测绘的站点单独下发一次侦察任务（工具条「资产侦察」，支持全部 / 选中）：

  • 产出面向资产画像的侦察报告，与渗透发现分开
  • 可单独停止、单独下载报告，也可打开侦察会话看过程

智渗透 ​

选中站点后点智渗透，把站点作为目标交给军团：

  • 支持单站与批量，批量任务有独立进度与暂停 / 继续
  • 已分析过的站点再下发会先停旧任务，避免两个会话抢同一目标
  • 完成后可从站点行直接打开产生报告的那次会话

任务中心 ​

  • 任务以页签排列，显示完成进度，可重命名、可删除
  • 任务中心面板集中展示本项目全部任务的进度与状态
  • 支持停止（选中 / 本任务 / 队列 / 全部）
  • 目标可从文件批量导入，重复目标自动去重

联动 ​

  • 与空间扫描联动 —— 端口扫描发现 Web 服务后可直接触发测绘
  • 与军团联动 —— 高价值站点交给军团深挖，军团也能自主下发测绘任务
  • 与漏洞管理联动 —— 验证出的发现进入同一本漏洞账本

典型流程 ​

  1. 从空间扫描结果选目标站点，或手动输入 URL
  2. 启动全站爬虫，观察资源树逐页展开
  3. 在指纹面板确认站点技术栈
  4. 对选中站点批量发起目录探测，发现隐藏入口
  5. 查看敏感信息抽屉，评估泄露面
  6. 把高价值站点「智渗透」给军团继续深入
