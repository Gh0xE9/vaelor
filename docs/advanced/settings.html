大模型配置 ​

  • 开箱即用预设：DeepSeek、GLM 智谱、通义千问
  • Anthropic Claude：原生接口格式
  • 自定义：任意 OpenAI 兼容端点
  • 多 Provider 并存，启用 / 禁用、切换默认模型、维护模型列表，保存后可做连通性验证

详见军团智能体。

智能体 ​

这一页管「军团到底怎么跑」，四个子页签：

执行环境 ​

项说明
Kali Docker 工具箱隔离环境之一，见 Kali 工具箱
WSL 工具箱隔离环境之二（Windows）
执行隔离档位不隔离 / 优先隔离（默认）/ 必须隔离

档位选了「必须隔离」而两套工具箱都没启用时，设置页会直接提示命令会被拒绝。

工具与钩子 ​

  • 本地工具 —— 军团能调用哪些本机工具
  • 钩子（Hooks） —— 把外部程序挂进动作链路：观察（只读旁路接收事件）或闸门（在工具执行前放行 / 拒绝）

全局行为 ​

参数说明
上下文窗口会话上下文长度上限，接近上限自动压缩
按模型覆盖为特定模型单独指定窗口与压缩参数
最大输出 Token单轮回复长度上限
重试次数模型 / 网络异常自动重试
模型请求超时单次调用的整体上限，中转排队久时调大
流式空闲超时多久没有新内容即判定挂死
折叠超长回复长输出自动折叠
子进程网络抓包留痕打开后子进程流量会留证
默认推理参数最大推理步数、温度等

遇到「大模型连接失败」

先调大模型请求超时与流式空闲超时。慢推理模型与排队严重的中转站，固定超时容易误判。

智能体角色 ​

维护内置角色与自建角色：系统提示词、可用工具开关、Skills 挂载。

  • 不勾选任何工具，表示允许该角色使用全部内置工具

空间测绘凭据 ​

管理四个测绘平台的 API 凭据，可查看积分余额与会员等级；凭据缺失时该平台在空间测绘页不可用，其余平台不受影响。

全局代理 ​

  • 全局 HTTP 代理 —— 所有出站请求统一走代理
  • 代理池 —— 维护多个出口，军团遭遇 WAF 封禁时自动切换
  • 代理路由 —— 按功能域单独指定出口（智能体 / 云上综合 / 目录扫描 / 大模型 / 消息通知 / 端口扫描 / 空间测绘 / 漏洞测绘 等）

详见代理与网络出口。

消息通知 ​

按通知组管理多个飞书 / 企业微信 Webhook，项目可绑定不同组，并按严重等级设置推送阈值。详见消息通知。

MCP ​

接入外部 MCP 工具服务器（本地进程或网络端点），扩展军团能力边界。详见 MCP 外部工具服务器。

Skills ​

技能文件的启用、编辑与导入；技能按需挂载到角色上。

外观与语言 ​

  • 主题 —— 浅色 / 深色，可跟随系统或手动指定；多套皮肤风格可切换
  • 界面语言 —— 简体中文 / English / 한국어，未手动选择时跟随系统语言
