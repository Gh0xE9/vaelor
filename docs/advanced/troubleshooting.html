排障手册 ​

本章汇总静默失败高发点与常见限制。遇到「没报错但结果不对」时，优先来这里对照。

一、先看这几类静默降级 ​

现象真正的原因处理
IP 归属全是「未知」缺少 IP 归属离线库按下载与安装的说明补上离线库
HTTPS 抓包只看到隧道信息、没有明文根证书未被信任在数据目录中找到抓包根证书并信任它
命令报「必须隔离执行，但没有可用隔离环境」档位为「必须隔离」且容器 / WSL 都未启用启用工具箱，或改档位
浏览器取证不可用没找到 Chrome安装 Chrome 后重启程序；已安装仍不识别请联系技术支持
空间测绘某平台报「无凭据」该平台 API Key 未配系统配置 → 空间测绘，补齐该平台凭据

二、代理类 ​

  • 配了代理但流量没走代理 —— 启用条件是「开关打开 且 链上至少有一个节点」
  • 只有某个功能不走代理 —— 检查代理路由里该功能域的出口设置
  • 容器检测判定为不可用 —— 检测超时很短，Docker 卡顿时会被误判为不可用，稍后重试

三、扫描与测绘 ​

  • 空间扫描单次目标数有上限，超出请拆分网段
  • 攻击面清单看起来不全 —— 超大站点的 sitemap 与表单会被截断，属保护性限制
  • 续扫后深层页面丢失 —— 未完成的队列不会保留，无法从入口页重新发现的深层页面不会恢复
  • ICMP 探测很慢 —— 缺少管理员权限时回落系统 ping
  • 界面刷新看起来「卡顿」 —— 进度事件有节流，属正常现象

四、空间测绘 ​

  • FOFA 返回「没有权限搜索 X 字段」 —— 低等级账号请求了高等级字段，平台会自动降档重试
  • 域名 / IP 模式查询内容不能为空
  • 每页条数受各家 API 约束

五、大模型与军团 ​

  • 模型不调用工具 —— 确认模型支持 Tool Use、角色工具开关已启用、Provider 连通
  • 连接失败 —— 先调大模型请求超时与流式空闲超时
  • 模型名大小写敏感 —— 必须与中转站控制台完全一致
  • 权限被降档 —— 「完全访问」不持久化，重开程序会回落，点顶部提示可改回

六、漏洞管理 ​

  • 发现列表是空的，但会话里有结论 —— 只有入账的发现才出现在这里
  • 严重度与报告里写的不一致 —— 账本严重度只升不降，重复登记取最重的一次
  • 某条发现写着「证据来自历史运行」 —— 该证据取自更早的运行，不计入本次战果
  • 侦察报告导不出 —— 侦察仍在进行时不允许导出，完成后再试

七、数据与实例 ​

  • 找不到数据 —— 数据在数据目录，或你另行指定的位置（见下载与安装）
  • 启动被拒「数据目录已被另一个进程占用」 —— 关掉另一个实例；并行跑必须用不同数据目录
  • 数据库被锁定 —— 确保没有其他实例在运行；仍不行则重启

八、平台差异 ​

  • WSL 工具箱仅 Windows
  • 数据目录位置 —— Windows 为程序所在目录，macOS 为系统的应用数据目录
