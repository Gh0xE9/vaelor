关于 VAELOR ​

VAELOR 是一款面向授权渗透测试与攻防演练的红队全链路平台 —— 桌面应用，单机运行，由 Gh0xE9 开发与维护。

它把资产发现、站点分析、自动化渗透与漏洞管理放在同一个应用里：数据按项目隔离，各模块结果互相引用，最终由军团智能体对目标发起多轮自动化作业，把验证过的发现沉淀进漏洞账本。

当前版本：DXE-1.0.0。

核心能力 ​

  • 军团智能体 —— 一句话下达任务，自动拆解为子任务并行推进，回收结论直到任务完成
  • 可控的自动化 —— 计划模式（先出计划再动手）、三档权限强制拦截、高危操作人工确认、命令可强制隔离执行
  • 资产测绘 —— 空间扫描、空间测绘（FOFA / Quake / Hunter / Shodan）、漏洞测绘三者结果统一入库
  • 漏洞管理 —— 发现直读账本、按严重度分诊；侦察报告按资产归集并可导出
  • 云上综合 —— 拿到 AK/SK 后枚举与利用公有云存储、云平台与 API 资产
  • 桌面助手 —— 常驻的小助手，一句话管项目、下发扫描、查阅漏洞
  • 三语界面 —— 简体中文 / English / 한국어

界面结构 ​

进入项目后，左侧是 7 个执行面板：

面板用途
仪表盘项目概览、资产与漏洞统计、模型用量、活动流
军团自动化渗透的主体工作区
漏洞管理发现分诊与侦察报告
漏洞测绘站点爬虫、指纹、敏感信息、目录扫描、智渗透
云上综合公有云开放平台利用
空间扫描端口扫描与服务识别
空间测绘测绘平台查询与入库

不在项目内时，左侧另有 首页、军团总览（跨项目会话看板），底部是 系统配置 与 关于。

数据与运行 ​

  • 所有数据保存在本地数据目录（项目、配置、证据、导出结果），不需要账号、不需要联网激活
  • 数据目录位置见下载与安装，需要时可改到别处

开始阅读 ​

  • 下载与安装 — 运行环境、数据目录与可选资源
  • 快速上手 — 十分钟跑通第一个项目
  • 项目管理 — 项目、目标资产与仪表盘
  • 军团智能体 — 核心工作区：计划、权限、隔离与模型配置
  • 漏洞管理 — 分诊口径与报告导出
