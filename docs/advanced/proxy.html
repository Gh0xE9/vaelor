代理与网络出口 ​

平台提供两套出口控制：全局代理（统一单一出口）与代理池（多出口轮换 + 故障转移）。

全局代理 ​

系统配置 → 全局代理 → 全局 HTTP 代理：指定一个代理节点作为当前出口，平台内出站请求统一走它。

代理池 ​

代理池维护多个出口，支持编排与自动切换。

能力说明
协议HTTP / HTTPS / SOCKS5 / SOCKS4
轮换策略轮询、随机、按时间、按请求数
节点串联多个节点可串成代理链
连通性检测记录延迟与存活状态

平台维护两个池：

实例用途
全局池除大模型外的所有流量
Agent 池军团遭遇 WAF 封禁时的故障转移出口

只加节点不开开关是无效的

启用条件是「开关已打开 且 链上至少有一个节点」，两个条件缺一，流量都不会走代理。

按功能域路由 ​

在代理路由里可以为不同功能单独指定出口：智能体、云上综合、目录扫描、大模型、消息通知、端口扫描、空间测绘、漏洞测绘等。默认跟随全局设置。

典型组合：

场景配置
统一走公司出口全局代理指定一个节点
防 WAF 封 IP代理池配置 3–5 个节点 + 按请求轮换，保持 Agent 故障转移开启
扫描直连、云上走代理只为「云上综合」单独指定出口
多级跳板把多个节点串成一条链

注意事项 ​

  • 修改设置或调整链会重置轮换状态
  • 代理节点需要认证时，先确认凭据格式被支持
  • 连通性检测是主动外连，目标不可达时节点会被判定为不可用
