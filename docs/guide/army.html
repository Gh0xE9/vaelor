军团智能体 ​

军团是 VAELOR 的核心工作区 —— 用一句话下达任务，它对目标发起多轮自动化作业，直到任务完成。

工作区布局 ​

区域内容
左侧会话栏会话列表：搜索、分组排序、置顶与归档、卡片 / 列表两种视图
会话头当前会话名、运行状态、视图切换
主对话区任务描述、工具卡、证据与结论，实时流式输出
右侧停靠面板并行任务、浏览器画面与请求响应、工具调用汇总、军团编辑过的文件

右侧面板宽度可拖动、可收起，用来在看结论的同时瞄一眼现场。

开场：选一个角色，说一句话 ​

新建会话时选一个角色：

角色定位
默认角色纯对话助手，参数调优与日常问答，不调用工具
红队角色打点闭环：全工具链、GetShell / RCE、内网路径评估
渗透角色SRC / 日常 Web 渗透：挖洞、浏览器取证、HTTP 报告
CTF 角色解题导向，目标明确地深挖单题
侦察角色资产侦察：指纹、框架、组件与攻击面整理，不挖洞

角色可配置系统提示词、可用工具开关与 Skills 挂载，也可以自建角色。

然后直接写任务，例如：

对 http://10.1.5.1:1180/ 进行授权渗透测试，全面发现并验证漏洞，输出报告。

计划模式：先看计划，再放行动手 ​

点输入框工具栏的计划按钮，本轮军团只做被动侦察与信息收集，产出一份计划卡：测什么、怎么测、预期确认什么、风险与前置条件。

确认无误后点**「批准并执行」**，下一轮即按计划开工。计划模式下主动扫描、爆破、写文件、派发子任务等动作会被拒绝。

权限模式：三档管控 ​

点输入框工具栏的权限按钮切换。这是执行前的强制拦截，被拦的操作不会真正执行。

档位能做什么
只读仅侦察与读取；命令执行与写操作一律禁止
工作区写入可写入工作区产物、执行 PoC 级命令；破坏性 / 横向移动 / 远程执行仍被拦
完全访问不做限制

完全访问不会被记住

重新打开程序后会回落为「工作区写入」，界面顶部显示提示，点**「恢复完全访问」**并二次确认即可改回。

高危操作人工确认 ​

即便在完全访问档，以下动作执行前也会弹确认卡：

风险类型举例
破坏性删除系统目录、格式化、关机重启
植入 / 反弹反弹 Shell、下载并执行植入体
横向移动SSH 远程执行、impacket / psexec / wmiexec 系列
远程执行批量远程扫描与动作

确认卡可勾选「批准并在本会话内自动批准」；超时未响应视为拒绝，动作留痕可查。普通 PoC 命令不会打扰。

执行隔离 ​

军团的命令可在本机或隔离环境（Kali Docker 容器 / WSL）中执行，档位在系统配置 → 智能体 → 执行环境中设定：

档位行为
不隔离命令在本机执行
优先隔离（默认）有可用容器 / WSL 就进隔离环境，否则本机执行
必须隔离没有可用隔离环境即拒绝执行，不会回落本机

每条命令的结果都标注它在哪跑的（隔离执行 / 本机执行）。工具箱的安装见 Kali 工具箱。

模型配置 ​

系统配置 → 大模型配置：

  • 开箱即用预设 —— DeepSeek、GLM 智谱、通义千问，填 API Key 即用
  • Anthropic Claude —— 原生接口格式
  • 自定义 —— 任意 OpenAI 兼容端点（中转、私有化部署均可）

多个 Provider 可并存，随时启用 / 禁用、切换默认模型；每个 Provider 可维护模型列表并做连通性验证。每轮对话的 Token 消耗按会话与项目汇总。

会话与记忆 ​

  • 同一会话内上下文跨轮次保留，长对话会自动压缩，不必手工开新会话
  • 会话可置顶、归档到文件夹，每个会话可单独设定模型参数
  • 工具执行异常时会自动拉起恢复通道，已完成的调用不重复执行

发现与报告 ​

  • 验证过的发现写入项目漏洞账本，在漏洞管理按严重度分诊汇总
  • 侦察报告按资产归集，可导出 Markdown / PDF
  • 交付前会做一次自检，拦截「有结论、无证据」的条目

消息通知 ​

配置飞书 / 企业微信 Webhook 后，高危漏洞确认等关键事件会自动推送，可按严重等级设置阈值。详见消息通知。

扩展 ​

  • Skills —— 技能文件按需挂载到角色
  • MCP —— 接入外部工具服务器，扩展军团能力边界
  • 钩子（Hooks） —— 挂接外部程序观察军团动作，或在工具执行前放行 / 拒绝

相关配置 ​

  • 默认参数 —— 系统配置 → 智能体 → 全局行为：默认模型、上下文窗口、最大输出、重试与超时
  • 执行环境 —— 隔离档位与工具箱
  • 代理 —— 军团探测的出口与 WAF 封禁后的切换，见代理与网络出口
