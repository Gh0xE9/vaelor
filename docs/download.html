下载与安装 ​

本章说明如何部署运行 VAELOR，以及首次运行可能涉及的可选资源。

当前版本：DXE-1.0.0。

运行环境 ​

依赖版本说明
Windows10 / 11系统自带所需运行时，无需额外安装
macOS12+（Apple Silicon）发行包为 .app，自签名
Docker Desktop可选军团的内网攻击能力依赖 Kali 容器，见 Kali 工具箱

VAELOR 开箱即用：发行包解开即可运行，不需要账号、不需要授权文件、不需要联网激活。

获取程序 ​

发行包/
├── VAELOR(.exe)   ← 主程序
└── browser/       ← 可选：随包 Headless Chrome 运行时

可执行文件名

对外产品名是 VAELOR；可执行文件名与数据目录名沿用 ErraticGopher，改名会牵动已有用户的数据迁移，故本期未跟随。

数据目录 ​

所有数据都保存在本机的数据目录里，与安装目录分开：

平台位置
Windows程序所在目录
macOS系统的应用数据目录（不在应用包内）

数据目录里包含项目数据、导出结果、作业工作区、技能与浏览器运行时、抓包根证书。需要迁移或备份时，把整份目录拷走即可；也可以把它放到其他位置。

找不到数据

扫描 / 项目数据在数据目录，不在安装目录。

可选资源 ​

资源说明
Docker Desktop军团的内网攻击功能依赖 Kali 容器，详见 Kali 工具箱
WSL无法安装 Docker 的 Windows 环境，可用 WSL 工具箱作为隔离环境
IP 归属离线库缺失时归属列显示「未知」，不影响其他功能
随包浏览器未随包时使用系统 Chrome / Chromium，见 无头浏览器与取证
