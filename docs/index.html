FAQ

常见问题速览

完整清单见常见问题与排障手册。

启动提示「数据目录已被另一个进程占用」？

同一份数据目录不能被两个实例同时打开。关闭已在运行的窗口后重试；确实要并行跑时，让两个实例各自使用不同的数据目录。

扫描或项目数据找不到了？

数据在应用数据目录（若你改过位置，则在指定处），不是安装目录。

军团不调用工具？

依次确认：模型支持 Tool Use、角色工具开关已启用、Provider 连通性正常；若处于计划模式，主动扫描与利用类工具会被拒绝。

提示「必须隔离执行，但没有可用隔离环境」？

执行隔离档位选了「必须隔离」但 Docker 与 WSL 都未启用。启用工具箱，或把档位改为「优先隔离」/「不隔离」。
