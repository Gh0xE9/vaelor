云上综合 ​

云上综合处理的是公有云开放平台：拿到一组 AK/SK 之后，枚举与利用云上资产。

版面 ​

区域内容
云资产栏已发现的云资产
凭据栏填 AK / SK（可选 STS Token），密钥字段为密码框
能力清单按四组组织：云存储工具 / 云服务工具 / 其他工具 / API 接口库
执行结果每一步的端点、方法、路径、请求体与响应原文

覆盖范围 ​

族覆盖
对象存储七牛 / 腾讯 COS / 青云 / 阿里 OSS / 又拍 / AWS S3（含兼容实现）/ 京东 / 金山 / MinIO
云平台阿里云 / 腾讯云 / 华为云 / UCloud / AWS

结果怎么看 ​

  • 能证明的才写结论：成功只认「返回成功且响应内无错误」，否则把对端原文摆出来由你判断
  • 不认识的接口不去猜：每一族都留了「自定义调用」入口，Action 与参数自己填
  • 不确定的前提写在说明里：需要开白名单、需要先开通服务的接口会标注出来
  • 一次性链接只展示不重放：例如控制台免登录链接，看一眼即失效

网络出口 ​

云上综合的出站可以单独指定代理，在系统配置 → 全局代理 → 代理路由里为「云上综合」选择出口。适合「扫描走直连、云上走代理」这类组合。

典型流程 ​

  1. 从代码仓库、前端 JS 或漏洞测绘的敏感信息里拿到一组 AK/SK
  2. 进入云上综合，选择对应的云平台或存储族，填入凭据
  3. 先跑「列举」类能力确认凭据有效，再按清单逐条深入
  4. 高价值结果留痕，回到漏洞管理分诊
