桌宠黑泽 ​

黑泽是常驻在界面上的小助手 —— 不必先组织完整任务描述，直接说人话就行。

拖动可换位置，点一下打开对话；有待确认的操作时，它会主动展开对话等你处理。

两种形态 ​

形态由你当前所在位置决定：

形态位置角色
首页形态还没进任何项目项目管家 —— 项目的增删改查
项目形态已进入某个项目侦察助手 —— 下发扫描、查阅漏洞与报告

能做什么 ​

首页形态

  • 列出 / 筛选项目，查看项目详情
  • 批量创建项目（「帮我建三个项目」）
  • 改名、改描述
  • 批量归档（可逆，数据保留）
  • 批量删除（不可逆，需两次确认）

项目形态 在上面的基础上增加：

  • 读取项目概况、目标资产、端口扫描历史与结果，并可下发端口扫描
  • 读取空间测绘资产，并可下发测绘查询
  • 读取测绘站点、测绘发现、高价值待测清单、API 攻击面与侦察报告，并可下发漏洞测绘 / 智渗透
  • 暂停、继续、停止已下发的测绘任务
  • 只读查看漏洞账本与报告全文
  • 资料检索：项目记忆、技能文档、联网搜索与网页抓取

能力边界 ​

黑泽不是第二个军团：读得多，动手少。

  • 不能执行命令、不能跑脚本、不能开浏览器、不能写工作区文件
  • 不能修改漏洞账本（账本是报告正文的权威来源，写错会污染交付物）
  • 不能爆破凭据、不能调用工具箱、不能派发子任务
  • 首页形态不能发起任何扫描或测绘 —— 那需要项目上下文

不在能力范围内的请求，它会明确告诉你做不了，而不是勉强试试。

确认策略 ​

操作确认次数
全部只读查询不询问
创建 / 改名 / 归档项目1 次（批量整批一次确认）
下发端口扫描 / 空间测绘 / 漏洞测绘1 次（会对真实目标发请求）
删除项目2 次（不可撤销）

拒绝的操作本回合内不再重复询问；删除时必须带上项目当前名称，名称对不上直接拒绝。

交互 ​

  • 真流式输出，逐字返回
  • 工具卡 —— 调用时显示「执行中」，结束后就地替换为结果卡，展开可见真实入参与返回值
  • 确认卡在消息流末尾，不遮挡它要批的操作说明
  • 停止按钮 —— 回合运行中可随时中断；单回合有步数与时长上限，到上限会给出阶段性结论

它改了什么，一眼可见 ​

黑泽替你改动数据后，界面上对应的位置会高亮标注：

位置标记
首页项目卡 / 最近项目外框 + 右上角标
空间扫描任务号与扫描历史行内角标 + 文字标记
空间测绘结果卡标题行内角标
漏洞测绘站点表行内角标

标记点击即消失，并且会保留下来 —— 刷新页面、事后再进来，标记都还在。
