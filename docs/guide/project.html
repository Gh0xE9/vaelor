项目管理 ​

项目是 VAELOR 的顶层组织单元 —— 所有扫描结果、军团会话与漏洞数据都归属于某个项目，天然隔离、互不干扰。

项目列表 ​

首页即项目列表：

  • 创建 / 归档 —— 按客户、按阶段组织作业单元；项目状态分活跃 / 已归档
  • 项目 ID —— 项目卡上可直接看到并一键复制，便于与他人核对同一次作业
  • 概况统计 —— 项目卡上给出资产与漏洞概况
  • 脱敏显示 —— 侧栏项目名可一键切换脱敏，适合演示与录屏

项目仪表盘 ​

进入项目后的第一屏。整页恒为一屏，内容在面板内部滚动：

顶部指标轨 —— 活跃任务、资产、漏洞等关键数字连成一条，每个数字附带构成比例，点击可跳到对应面板。

五个分区：

分区内容
概览模型用量趋势、风险构成、今日流量、近 30 天作业趋势
资产态势攻击面雷达、攻击面分布、测绘概览、今日扫描活动
风险线索TOP5 风险网站、TOP5 漏洞，点击可跳转对应模块
动态军团与各模块的近期动作时间线
工具矩阵常用模块的快捷入口

目标从哪来 ​

平台不设单独的目标录入页 —— 目标在你下发扫描、测绘或让军团作业时自动登记到项目里：

  • 空间扫描填入的 IP / CIDR / 域名
  • 空间测绘拉回的资产
  • 军团在作业中发现的站点与主机

登记后的目标可被各模块引用，也可被桌宠读取（「这个项目有哪些目标」）。

扫描现场 ​

各扫描类面板的页签布局会自动保存，下次进入时恢复现场。

数据位置 ​

每个项目的数据（资产、扫描结果、漏洞、会话）都在数据目录内按项目分开存放，导出的报告与结果另有一处固定目录。备份或迁移时把整个数据目录带走即可。

TIP

数据目录的位置与迁移方式见下载与安装。
